# Functional cis-regulatory variation in Duroc × Luchuan F1 pigs

Code accompanying *Multi-omic profiling and MPRA of hybrid pigs uncover extensive functional cis-regulatory variation undetectable in purebreds*.

The scripts generate selected figure panels and associated Source Data from processed study inputs. DLC denotes the Duroc × Luchuan F1 population. DU and LC denote Duroc and Luchuan, respectively.

## Running the scripts

Open the relevant figure directory and follow its README for dependencies, expected input columns, example commands and outputs. Python dependencies are listed in each module's `requirements.txt`. The module READMEs also document R packages and external tools where required. Example commands assume paths relative to the figure directory. Use explicit input paths and a separate output directory for each run.

Some panels require original analysis files in addition to the scripts in this repository:

- **Fig. 2e** requires the original statistical analysis for the Kruskal–Wallis and Dunn tests shown in the manuscript.
- **Fig. 3e** includes generation of the Duroc MAF-filtered position list. The original heatmap plotting script is required for the panel.
- **Fig. 4f** requires `plot_all_DLC_MAF005.py` and the overlap-status table generated by Fig. 4e.
- **Fig. 5b and 5f** require `MPRAmodel.R` from the original MPRASuite analysis and `pearson_p_exact.py`, respectively.

## Data availability

See the manuscript's Data Availability statement for sequencing data and study resources. The [pigRegDb database](https://gonglab.hzau.edu.cn/pigRegDb) provides study data. External comparisons use [PigGTEx](https://piggtex.farmgtex.org/) and PigBiobank. Each module README specifies the processed inputs required for the example commands.
