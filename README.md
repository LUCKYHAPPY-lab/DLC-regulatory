# Functional cis-regulatory variation in Duroc × Luchuan F1 pigs

Code accompanying *Multi-omic profiling and MPRA of hybrid pigs uncover extensive functional cis-regulatory variation undetectable in purebreds*.

The scripts generate selected figure panels and associated Source Data from processed study inputs. DLC denotes the Duroc × Luchuan F1 population. DU and LC denote Duroc and Luchuan, respectively.

## Figure modules

| Directory | Panels | Analysis |

| [`figure2_population_genomics/`](figure2_population_genomics/README.md) | 2e–g | Expected heterozygosity, overlap of polymorphic positions and the joint FST–nucleotide diversity selection scan |
| [`figure3_cis_eqtl/`](figure3_cis_eqtl/README.md) | 3a–f, with preprocessing for 3e | Cis-eQTL distributions, PigGTEx overlap, Duroc MAF inputs and effect harmonization |

| [`figure6_regulatory_network/`](figure6_regulatory_network/README.md) | 6a–b | emVar–gene–trait network and regional evidence at chr7:23,797,335 C>T |

## Running the scripts

Open the relevant figure directory and follow its README for dependencies, expected input columns, example commands and outputs. Python dependencies are listed in each module's `requirements.txt`. The module READMEs also document R packages and external tools where required. Example commands assume paths relative to the figure directory. Use explicit input paths and a separate output directory for each run.

Some panels require original analysis files in addition to the scripts in this repository:

- **Fig. 2e** requires the original statistical analysis for the Kruskal–Wallis and Dunn tests shown in the manuscript.
- **Fig. 3e** includes generation of the Duroc MAF-filtered position list. The original heatmap plotting script is required for the panel.
- **Fig. 4f** requires `plot_all_DLC_MAF005.py` and the overlap-status table generated by Fig. 4e.
- **Fig. 5b and 5f** require `MPRAmodel.R` from the original MPRASuite analysis and `pearson_p_exact.py`, respectively.

## Data availability

See the manuscript's Data Availability statement for sequencing data and study resources. The [pigRegDb database](https://gonglab.hzau.edu.cn/pigRegDb) provides study data. External comparisons use [PigGTEx](https://piggtex.farmgtex.org/) and PigBiobank. Each module README specifies the processed inputs required for the example commands.

## System Requirements & Installation
- **Operating System:** Linux (tested on Ubuntu 20.04 / CentOS 7)
- **Software Dependencies & Tested Versions:**
  - Python (v3.9; `pandas`, `numpy`, `scipy`, `statsmodels`)
  - R (v4.3.1; `dplyr`, `data.table`, `MatrixEQTL`, `TreeQTL`, `poolr` v1.2.0, `DESeq2`)
  - Bioinformatics command-line tools: `fastp` (v0.23.4), `BWA` (v0.7.17), `GATK` (v4.4.0.0), `Beagle` (v5.4), `HISAT2` (v2.0.5), `StringTie` (v1.3.3), `PLINK` (v1.9), `VCFtools` (v0.1.16), `ADMIXTURE`, `PopLDdecay` (v3.43), `bedtools` (v2.26.0), `SnpEff` (v5.4.0c), `MPRAsuite` (`MPRAmatch`, `MPRAcount`, `MPRAmodel`), and `MEME Suite` (v5.5.9; `AME` and `FIMO`).
- **Hardware:** No non-standard hardware is required.
- **Installation Guide:**
  - Clone the repository: `git clone https://github.com/LUCKYHAPPY-lab/DLC-regulatory.git`
  - **Typical install time:** < 5 minutes on a standard desktop computer (assuming standard Python/R environments are available).

## Demo & Usage

- **Demo Dataset (`demo/demo_data.xlsx`):** A lightweight, sanitized and downsampled demo workbook (preserving all 51 worksheet schemas and column formats, with ≤30 rows per block, perturbed numerical values, and anonymized IDs/loci) is provided in `demo/demo_data.xlsx` to test code execution and input/output formatting prior to publication. Full Source Data will be made available upon formal publication.
- **Expected Output (`demo/expected_output/`):** Representative expected output figures generated from simulated demo data are provided in `demo/expected_output/`:
  - `demo_fig2.png` (Fig. 2e–g: expected heterozygosity, variant overlap, and selection scan)
  - `demo_fig3.png` (Fig. 3a–f: cis-eQTL distribution, effect-size/MAF correlation, and PigGTEx comparison)
  - `demo_fig4.png` (Fig. 4a–f: ASE ratio distribution, genomic annotation, and breed overlap)
  - `demo_fig5.png` (Fig. 5b–d, f: MPRA replicate correlation, allelic skew, chromatin enrichment, and GC content)
  - `demo_fig6.png` (Fig. 6a–b: multi-layered emVar–gene–trait network and regional locus tracks)
- **Instructions to Run on Demo Data:** Follow the example commands in each module's README using the corresponding sheets from `demo/demo_data.xlsx` (or module-specific example inputs).
- **Expected Run Time:** < 1 minute for the demo dataset on a standard desktop computer.
- **Instructions for Use on Custom Data:** Replace the input file path in the analysis scripts with your own formatted genotype, expression, or MPRA count matrices following the column schemas in `demo/demo_data.xlsx` and each module's README.
